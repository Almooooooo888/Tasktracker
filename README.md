# Taskboard для Jira

Taskboard 1.18.0 показывает задачи Jira, помогает вести регресс и собирать состав релиза по Fix Version с фильтром Jira labels. Вкладка сборки может создавать связи `relates to` с релизной задачей после явного подтверждения пользователя. Docker-образ не содержит Jira-токенов, пользовательских сертификатов или профилей.

## Запуск Docker-образа

1. Скопируйте `.env.example` в `.env` и укажите URL Jira в `LK_JIRA_BASE_URL`. В примере используется `https://jira.example.com`.
2. Если Jira или GitLab используют корпоративный центр сертификации, поместите публичный CA-сертификат в PEM-файле `certs/jira-ca.pem` и раскомментируйте `NODE_EXTRA_CA_CERTS=/run/certs/jira-ca.pem` в `.env`. Тот же файл подхватывается при запуске через `Start.cmd` в Windows. Приватный ключ или пользовательский PFX сюда не копируйте.
3. Запустите `docker compose -f compose.hub.yaml up -d` и откройте `http://127.0.0.1:18764`.
4. Каждый пользователь вводит собственный Jira-токен в настройках приложения. Он хранится в локальном Docker volume, отдельно от образа.

Docker-версия проверяет TLS-сертификат по умолчанию; `LK_JIRA_TLS_SKIP_VERIFY=true` отключает эту проверку. Локальный запуск Windows через `Start.cmd`/`Restart.cmd` пропускает проверку для совместимости с dev Jira, как это делала версия 1.17.0. Порт приложения опубликован только на loopback-интерфейсе. Не удаляйте volume `profile`, если нужно сохранить локальный профиль.

Для прямого поиска веток и MR укажи адрес GitLab и токен с областью `read_api` в настройках профиля. Windows сохраняет его с помощью DPAPI; в Docker профиль лежит в отдельном томе, доступном администраторам Docker. Можно также задать `LK_GITLAB_BASE_URL` и `LK_GITLAB_TOKEN` в локальном `.env`: токен применяется только в GET-запросах. Не коммить `.env` и не публикуй его: переменные контейнера видны администраторам локального Docker daemon. Поиск ограничен десятью задачами за загрузку релиза, двумя параллельными запросами и кэшем на 5 минут. Без токена приложение продолжит показывать данные Jira.

Если Jira доступна только через VPN или внутреннюю сеть, подключитесь к ней до запуска приложения.
