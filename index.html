Настройки профиля

Введи свой Personal Access Token из профиля Jira.

Необязательно. Нужен токен с правом read_api для поиска MR и веток.

Токен сохраняется на компьютере, где запущена программа. В Docker — в отдельном томе, доступном администратору Docker. В Windows — зашифрован средствами Windows.
